How to Join

  • 1. Install: NeoForge Client
    • You must have a previously played install of Minecraft before continuing. So open your Minecraft game and enter the home screen. Now close it. This step generates the necessary files to place the mods folder and other files we need to install this client.
    • Install the NeoForge 26.3 installer (the same NeoForge version as the server) for Minecraft version 26.3 — neoforged.net
    • Open NeoForge, click "Install client", then click "Proceed"
  • 2. Install: Tailscale VPN
    • Install the free Tailscale VPN app and create an account — tailscale.com/download
    • Accept the Tailscale invite from the admin.
    • Under Machines, find the Minecraft server machine the admin shared with you and copy its IP address — you'll use this in Minecraft "Multiplayer".
  • 3. Download Mods
    • Download the full mod list above and unzip the files.
    • On PC, drop the .jar files into .minecraft/mods inside your Minecraft game folder.
    • On Mac, drop the .jar files into ~/Library/Application Support/minecraft/mods.
    • If no mods folder exists, create one first. Need help finding the folder? wikihow guide
    • Make sure you are on admin's server whitelist
  • 4. Connect
    • In Minecraft Launcher: If NeoForge 21.6.20 is not listed, go to → Installations → New Installation and choose the version we need. Otherwise, launch Minecraft {{ version }} using theNeoForge profile
    • In Minecraft, go to Multiplayer → Direct Connection and paste the Tailscale IP address from Step 2.
    • Send admin any error messages you exerience.
